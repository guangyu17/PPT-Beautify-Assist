# PPT Beautify Studio 技能目录

当前正式版本见 [SKILL.md](SKILL.md) 的 metadata.version。安装时复制整个本目录，保持目录名 `ppt-beautify-studio`。

| 入口 | 用途 |
|---|---|
| [SKILL.md](SKILL.md) | 技能触发条件、工作模式和按需参考 |
| [agents](agents/README.md) | Codex 显示名称与简介 |
| [config](config/README.md) | 仓库默认设置 |
| [references](references/README.md) | 各模式与设计能力的细节 |
| [scripts](scripts/README.md) | 本地处理与验证辅助工具 |

README 用于目录导航；实际执行规则以 SKILL.md 及相关参考为准。维护仓库不代表执行一次 PPT 美化流程。
