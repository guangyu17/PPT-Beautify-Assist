# 四档美化：超高 / 高 / 中 / 低

用户列出了四个名称，因此实现四档，而不是合并成三个。档位决定投入与素材复杂度，不决定主题是否花哨。
例如“超高＋简约”是在简约约束内精修，不强制塞入史诗边框；数据密集页不能因档位高而牺牲可读性。
新任务未指定且无持久档位时问一次；先盘点整套、说明预计生图数量/复用与可能成本，确认后做样张。
输出质量、原文保真、完整页数、原生文字、字体检查与真实渲染是所有档位的底线。

| 档位 | 背景与图片 | 图标/线框/材质 | 工作节奏 |
|---|---|---|---|
| 超高 ultra | 在用户允许的主题范围内按页定制，精细抠图/延展/融合、分层光影和alpha；可启用一体化场景 | 全面规划有语义依据的图标/时间轴/结构线、丰富且统一的装饰；材质框必须真实生图 | 所有适用能力充分利用，不为凑素材强行加无关组件；先样张再整套，累计重试仍有界 |
| 高 high | 是否生成逐页背景听用户需求，不默认每页生图；重点主视觉与整套统一 | 减少多余线框/对话框；可生成并复用全套边框和关键图标。需要材质框必须生图 | 重点页精修，其余复用；不因高档自动生成大量背景/面板 |
| 中 medium | 优先原图＋本地融合、少量共用背景/章节图，纯色原生底优先 | 原生清晰线/节点，精简图标；默认无材质对话框，确需时单独确认生成并复用 | 分页按需读取、复用资产与prompt，少做无效尝试，节省图像调用和上下文 |
| 低 low | 文字＋已有图片＋简洁原生底，不主动重新生成大背景 | 轻边框或细分隔线，可复用已有/少量生成边饰；默认无材质框/多层华丽花纹 | 简约商业/学术风为默认建议，保留用户品牌与字体偏好；更少生图但仍完整可编辑 |

## 对话框/卡片材质强制规则

本版把过去“原生半透明矩形＝精致对话框”的默认做法撤销。用户所称对话框也包括承载叙事文字的
玻璃/亚克力/纸纹/雕花卡片：**只要要这种面板，就用真实生图的无字材质图＋原生文字**。
超高/高时尤其禁止降级到原生平板或静态模糊取样假装满足；中/低默认省略面板，不为省钱而伪造质感。
简单原生文字框（无填充）、时间轴线、节点、细框/安全底板不是上述展示材质，可以原生实现；
不能把面板改名shape绕过规则，也不能把背景截图模糊后声称是生图面板。
生图素材未到或不合格，停下说明该组件未完成、按用户同意省略，不能悄悄替换为普通矩形。

计划里记录面板主题、比例、文字安全区、独立对象需求与复用范围。不同字数/尺寸的面板不要拉伸同一PNG，
先选合适的比例/切片方案，再将正文独立排版。边饰透明与alpha、正文对比仍需看实际渲染。
生成的纹理PNG不是矢量，不能承诺内部纹路可逐笔编辑；文字和整个面板对象可独立编辑/替换。

## 可执行布局合同

新版代理必须写入顶层profile，供组合器及lint共同检查：

```json
{
  "studio_profile": {"tier": "high", "backend": "native"},
  "aspect": "16:9",
  "slides": [{"elements": [{
    "type": "panel", "id": "story-card", "x": 1, "y": 2, "w": 8, "h": 2,
    "material": "acrylic", "material_source": "generated",
    "texture": "../ornaments/generated/panel-r01.png",
    "fill": "#FFFFFF", "alpha": 0.06, "inset": 0,
    "text": "保留原文，单独可编辑", "size": 24, "padding": 0.25
  }]}]
}
```

这是协议样例，未提供的panel文件不能假装存在。脚本检查generated声明及图片存在，
**不能单凭字段证明图像由AI生成**；代理须对照真实生成日志和文件哈希。
旧版无profile布局仍能回归测试/还原，不能把“移除profile”用于新项目规避门禁。
保存backend/tier、预计独立资产与复用清单到layouts/deck-style.json，后续对話不用重问已确认选择。
