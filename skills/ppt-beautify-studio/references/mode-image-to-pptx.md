# 模式2：页面还原为可编辑PPT

PDF页面、截图、扁平PPT，目标是原貌还原，不主动换设计。按 [通道](image-backends.md) 读取持久生图选择，默认native。
本次档位不改变文字/数据保真底线，不为了低档省图擅自删内容或把整页截图当背景。
用extract_pdf.py渲染PDF/抽文字层与原图，记录页序；没有文字层标needs_ocr，脚本不假造OCR。
扁平PPT先实际渲染，仍有原生文字则保留；拼图拆单页，混合比例/未知文字先问。
从原页区分文字、独立图片/图标、背景；可从原图裁出则不生成。看不清的数字/人物身份不能补猜。
需要清底、抠图或补环境时用选定通道，按原页注册画布保持构图；IFAPI桌面按 [请求预检](payload-budget.md) 后调用。
文字全原生，字号优先PDF pt；截图按目标页物理尺寸/原像素估算后视觉校准，不直接把OCR像素数当pt。
原页含图标/面板/时间轴时忠实分层；已有原稿面板的准确裁片可保留，不将新设计中的“生图面板优先”当成重绘原稿授权。
底图中要移除另行回填的文字/前景，不做重复影像；背景还原不把标签画回去。
按 [图像融合](image-blending.md)、[布局协议](layout-typography.md) 和 [视觉闭环](visual-review-loop.md) 对照原页逐项验证。
记录AI补全区域与独立图片/原生对象边界；不能证明每个像素都原生可编辑。
用户明确继续美化才转模式1，不因原页有文字/边框就强行推华丽风或换字体。
