# 模式3：大纲生成

按 [通道](image-backends.md) 默认native，按 [四档](beautify-tiers.md) 确认本次投入，不重复问已持久设置。
Word/Markdown先提取材料，不编造数据；商业汇报先按 [故事线](storyline-pyramid.md) 规划：每页一句结论标题、分论点数量、事实支撑缺口（标“需补充事实”并问用户，不补造）。
学术、叙事等场景仅在用户要求时采用这套框架，否则按用户材料和目标组织结构，不强制将标题改为论断。
再列出所有页标题、要点、页面类型与建议配图，先确认页数结构。
按 [全套合同](deck-style-contract.md) 确认字体/色彩/家族与预算，再提供代表页真实样张并等用户选择。
背景是否生成按用户需要和档位；高档不等于全页强制生背景，低档以文字/原图/边框为主。
[语义组件](semantic-components.md) 依据材料规划，所有材质对话框都要真正生图＋独立原生文字，无素材不能降级。
全部生成使用选定通道，IFAPI桌面才执行 [预检](payload-budget.md)，原生默认豁免该临时体积门禁。
规划确认/风格样张门均通过后才整套生成；文字原生、图片独立，只有明确批准的一体化视觉背景是局部例外。
按 [归档](asset-workspace.md)、[布局](layout-typography.md) 和 [视觉闭环](visual-review-loop.md) 制作与验收。
复杂SVG排版可按ppt-master单一路由完整复用并遵守其门，不改其脚本、不偷偷采用其供应商默认。
