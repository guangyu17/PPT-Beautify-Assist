# 有辨识度的 PPT 设计与减法精修

模式1的视觉重设计、模式3的新建演示使用；只做局部修复时直接处理指定问题。模式2忠实还原时不套新风格、减装饰或重组原稿。先遵循原文、样张、档位、通道和费用边界。

## 把讲述意图写成 brief

先从材料和用户指令提取受众、观看场景（投影/屏幕/阅读版）、时长、讲述目的、品牌及喜欢/反感的细节，只问影响设计的缺口。将喜好变成可操作约束，例如“克制”落实为开放留白、清楚的字阶、少量强调色，而不是空泛写“高级”。

在 `layouts/deck-style.json` 的 `design_brief` 记录：

| 字段 | 要写出的实际决定 |
|---|---|
| audience / viewing_context / communication_goal | 谁在何处看，首先应读懂或记住什么；未知项显式记 unknown |
| intended_feeling / visual_metaphor | 要传达的感受；视觉隐喻如何帮助讲述，可明确不用隐喻 |
| composition / reading_path | 主次、视线起点、留白与内容的组织方式 |
| typography / palette / image_role | 字体角色、颜色职责、图像承担的信息及已有素材来源 |
| avoid / preserve | 用户反感的具体元素；必须保留的文字、页序、来源与对象 |
| sample_scope / asset_budget | 样张页号、允许生成的素材及数量；不生成就明确记0 |

这些字段由代理维护，不是 `compose_slide.py` 自动消费的新协议。不确定的素材、字体和版式可行性写为待核验，不伪装成现成资源。

## 提供真正不同的方向

未定方向时，在已有全套盘点上提出2–3个可比较的概念。每个概念都写：目标感受、核心视觉隐喻或不用隐喻的理由、构图/阅读路径、字体角色、图像用途、具体避免项，以及它为何适合这套内容。至少在构图、信息组织、字体角色或图像用途中的两项有实质区别；仅换配色不能构成新方向。

例如游戏开发复盘可比较“作品刊的图文跨栏”“开发日志的证据注记”“关卡路径的迭代节点”。路径只表示原稿已有的顺序；经验、问题和数据不能因隐喻被凭空连成因果。示例是思路，不是每套PPT必用的模板。

在合同的 `directions` 记录候选；用户明确方向时只细化该方向并写 `selected_direction`，不强迫再选三种。先简述概念，确认设计范围后制作封面＋复杂内容页的实际样张；样张批准前不生成其余页。未拿到全稿时只作局部提案，仍不能宣称整套规划完成。

若始终重复同一模板，可选用本地 `secrets.token_hex` 的真实随机结果探索分组或节奏，记录在本次项目，不显示到幻灯片、不写长期偏好，也不改变用户已定方向。无需为了“有个性”使用随机、插画或动画。

## 从真实渲染提出可执行问题

先按 [视觉闭环](visual-review-loop.md) 生成并实际查看 PPTX 的真实渲染。评审输入为本轮渲染图、受众/观看场景、brief 和必要质量参考；有独立代理且本次允许委派时可用新上下文评审，否则明确为自查。不给评审者代码、实现困难、历史辩解或目标分数。

评审提示可用：

> 先概括这套样张的视觉意图，再检查阅读顺序、字体、留白、配色、图像整合及跨页一致性。列出最多三个最影响讲述的问题；每项写页号与区域、可见现象、对受众理解的影响、具体修改动作。指出可删的无用途装饰，并说明须保留的内容。没有图片证据的事项记为未验证，不从截图推断文字对象可编辑、事实正确或演讲时长合适。

先安排最多两轮审美精修，每轮修改最重要的1–3个问题、重新组合/渲染并对照。两轮计入原有每页最多4轮本地修复，不重置 API 重试和资产预算。溢出、遮挡、丢字等交付缺陷继续按原有闭环处理；仍不合格就保留最好版本、标明缺口。不得用“审美两轮结束”放行缺陷，也不为追求分数无限迭代。主观分数仅作参考，不作为交付门禁。

`logs/visual-review.json` 内追加 `design_review`：brief版本、评审方式（self/independent）、本轮图片、问题位置/影响/动作、修改前后证据、实际删减与停止原因。此记录不替代真实看图、原文核对及对象可编辑性检查。

## 减法检查的单位是视觉元素

逐项说明装饰是否支持阅读、讲述或所选感受；没有用途的重复边框、额外标签、空容器和抢焦点的效果可省略。渐变、卡片、不对称等不是一概禁止，按实际用途判断。

模式1保留全部原文、原有强调、数据、图例、来源、页数与顺序。视觉重排可以减少装饰，不能把原文标题/标签称为冗余后删掉。模式3仅精简允许编辑的草案表达；用户给定的引用、数据及受保护内容仍保留。材质面板可按用户方向省略，需要时仍用真实生图素材；不改名成原生矩形绕过材质规则。不得把整页含字扁平化来获得整洁效果。
