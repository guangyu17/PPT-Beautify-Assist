# 真实效果评审与减法

评审输入：本次brief、实际页面/幻灯片渲染、与变化相关的状态或运动证据、必要质量参考。若允许独立代理，使用新上下文；不给代码、实现困难、历史辩解或目标分数。没有独立代理就明确自查。参考作为质量基线，不要求照抄；可比较多张匿名图。

评审输出：概括视觉意图，列出最多三个最影响主任务的问题。每项写位置/时间点、可见现象、影响和可执行修改。检查构图、字阶、读序、间距、配色、图像融合、组件一致性；动态另看注意力、因果、接缝、中断与返回，不能只评最漂亮的一帧。

先安排最多两轮审美精修，已无具体问题即停止；比较是否收敛，每次变更要重跑受影响状态，主任务故障、不可读或播放失败不得靠主观分数放行。达到宿主预算或无改善时保留最好版本和具体缺口，不能无限追分。

减法先问每个视觉元素是否帮助理解、操作或所选感受。去除无用途的容器、效果、重复说明；保留必要标签、错误/加载状态、可访问名称、数据图例和来源。原生组件更合适时可使用原生组件；渐变、卡片和不对称不是自动错误。PPT原文/顺序/对象的保护由主技能规定，不能借“去模板感”删字或全页扁平化。

交付分别记录：静态视觉、交互路径、运动/播放、性能、减少动态/静态回退的证据与未测项。证据来自当前产物，旧截图不能代表更新后的shader或动画；图像中的画面正确也不能证明对象可编辑。
